A Jack in the Box application was developed using C++ and wxWidgets, where the character Sparty pops out after a timed sequence accompanied by a music box animation. The project included the creation of an adapter class for integration into an existing codebase with customizable start frames, along with the implementation of a keyframe-based movie system enabling character interactions and XML-based load/save functionality.
